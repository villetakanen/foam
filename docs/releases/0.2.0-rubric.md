Frozen 2026-09-23 before changing the 0.1 interpreter prompt. The synthetic case
catalog is `tests/fixtures/semantic-cases.json`; the original prompt is retained
in `tests/fixtures/inference-0.1.ts.txt`. Historical baseline traces remain in
`docs/evaluation-*.json`. New same-harness baseline runs must be recorded separately.
Tuning uses the bundled Luma R8 case; held-out trials use Neri H6 dimensions and
alternate ambiguous, negated, corrected, completed and interrupted encounters.
Do not tune against held-out failures and then call a rerun held-out evidence.

Review each operation's stored Markdown, evoked context and client reply separately.
Assign pass/fail and quote supporting evidence for each applicable dimension:
entity identity; dimension association; relevant context; unrelated activity retention;
reference resolution; grounded continuation; completion; invented obligations.
A correctly unresolved reference should prompt clarification. Needless clarification
when the evidence identifies the subject is a continuation failure. Client replies
must not claim a note update without tool evidence. Host task state is identical in
both conditions. Protocol errors count as failures, never discarded samples.
Automatic keyword matching and successful JSON decoding cannot assign semantic passes.
The runner leaves human scores unassigned and retains every failure and raw output.

Targets: 20 radiator trials, 20 completion trials; zero identity substitutions,
reassociated dimensions, invented obligations or obsolete action suggestions;
at least 18/20 useful radiator continuations. Ten sequences of ten accesses must
retain unrelated ongoing activity in Markdown and omit irrelevant view content.
Compare enabled/disabled with the same responding model, host task and current
project context. Publish warm prepare/observe p50/p95, cold first-call latency,
call and byte counts, and provider token counts when available. Warm preparation
p95 target is <3 seconds. Small samples do not establish a reliability percentage.
