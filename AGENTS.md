# FOAM

FOAM explores fleeting, partial recollection that adds contextual awareness.
Useful associations and focused clarification count; complete task-state reconstruction
is not the goal. Read `VISION.md` and `specs/memory/spec.md` before changing policy or evals.
Preserve the distinction between biological evidence and engineering hypotheses.

- Use `npm run check` and both demos before release. Behaviour changes update
  `specs/memory/spec.md` in the same commit.
- Markdown is the memory. Analysis covers the whole authorized scope; returned
  context has a separate budget. Access may change memory.
- Scope is explicit host configuration, never inferred from conversation or model output.
- The six ignored study notes under `docs/` are local research inputs, not public artifacts.
- Consult ASDLC.io practices when changing project practices; see `CONTRIBUTING.md`.
